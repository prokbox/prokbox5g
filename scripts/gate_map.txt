# Gate --changed coverage map (docs/process.md "Gate").
#
# One rule per line: <path-glob>  <script-name-pattern>...
# Whitespace-separated; a path-glob with no wildcard is just a literal
# path. The second-and-later columns are script-name glob patterns
# (matched against tests/ui/*.script basenames, e.g. "ipodui-p4-*"), or
# the single word ALL.
#
# validate.sh --quick --changed maps every changed file (git diff against
# the merge-base with main, plus uncommitted changes) through this table.
# A changed path matching ALL on any line, or matching NO line at all,
# makes the run cover every ipodui-* script (the safe default — an
# unmapped file is an unknown risk, not a free pass). Only the ipodui-*
# selection is narrowed; stock scripts, builds and host tests are
# unaffected, and the plain full gate (no flags) always runs everything.
#
# Keep this table in sync with apps/ipodui/ as screens/features are
# added; when in doubt, map to ALL rather than guess narrow.
