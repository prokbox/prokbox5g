# Format: one trim per line, "NAME: NEED NEED ..." (names without the
# IPODUI_TRIM_ prefix). "A: B" means bringing A back (deleting its line from
# the header) also needs B back, because A's code calls into B. A trim's
# revert closure is A plus everything reachable from it over these edges;
# scripts/trim-revert.sh deletes the whole closure and builds each distinct
# closure once. An empty need list is a leaf (as far as known: a leaf whose
# revert fails to build is a missing edge, added here and to the header).
#
# Conditional lines (the header only sets them in some variants):
#   IAP      only without --dock30 (reverting it == the dock30 build)
