# Native USB screen: reference art

Generated by `art/usb/usbscreen.py` (stdlib only), which also writes `apps/ipodui/usbscreen_data.h`. Don't edit these files by hand: change the generator and rerun it. `tests/usbscreen/run.sh` fails when the committed header or PNGs differ from a fresh run, or when the firmware's C (built on the host) differs from these PNGs by a single pixel.

The PNGs show the screen **without its text, header title and battery**. The firmware draws those with the shell fonts and `ui_header_draw_dark()`. Colours are expanded from RGB565 the way the simulator's screenshots expand them, so a sim shot and a PNG compare pixel for pixel outside those areas.
